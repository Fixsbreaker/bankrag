# Материалы для защиты: видео и слайды 2, 4, 8

Скриншоты и видео делаются после замены учебных документов на реальные (см. `docs/dataset.md`). Запись экрана и скриншоты выполняет человек, здесь только сценарий и тексты.

## Видео-демо (до 5 минут)

Подготовка: индекс построен, `.env` заполнен, `streamlit run app.py`, окно браузера на вкладке «Чат», шрифт крупно.

| Время | Что показать | Что сказать |
|---|---|---|
| 0:00–0:30 | Заставка и вкладка «Чат» | Что за проект и какую проблему решает (одна фраза со слайда 2) |
| 0:30–1:30 | Вопрос 1 про комиссию или тариф (с числом). Раскрыть источник | Ответ взят из документа; показываю фрагмент, число совпадает |
| 1:30–2:30 | Вопрос 2 другой формулировкой, без слов из документа | Ищет по смыслу, а не по словам |

Вопросы 1–4 выбрать из `data/eval/refusal.json` (после обновления под реальные документы). Заранее прогнать каждый, чтобы в кадре не было сюрпризов. Записать два дубля.

## Слайд 2. Проблема
- Заголовок: **Ответ в банковских документах найти долго, а выдуманный ответ опасен**
- Три пункта: поиск по словам не понимает смысл вопроса; тарифы и условия разбросаны по десяткам PDF; обычный чат-бот может выдумать комиссию или срок.
- Одна цифра для акцента: [сколько документов и страниц у одного банка, посчитать на реальных данных].
- Заметки докладчику: привести пример, где неверная цифра стоит денег клиенту или банку.

## Слайд 4. Решение
- Заголовок: **Вопрос → поиск по смыслу → ответ со ссылкой на источник**
- Схема из трёх блоков: «Вопрос» → «Поиск ближайших фрагментов (векторный индекс)» → «Ответ только по фрагментам, `[1]`, `[2]`».
- Под схемой две строки: «нет ответа в документах: честный отказ»; «числа из ответа сверяются с источником».
- Заметки докладчику: объяснить, что модель видит только найденные фрагменты, а не весь интернет.

## Слайд 8. Демо
- Заголовок: **Так это выглядит**
- Три скриншота подряд: (1) вопрос и ответ с источником; (2) раскрытый фрагмент с текстом; (3) отказ на вопрос без ответа.
- Подпись к (3): «Проверка на 6 вопросах без ответа: отказов [X из 6]».
- Заметки докладчику: готовы показать живое демо, если видео не нужно.

## Вопросы на защите про галлюцинации и модель (короткие ответы)
- *Как вы не даёте модели выдумывать?* Промпт «только по фрагментам», маркер отказа, ссылки на фрагменты, сверка чисел с источником, проверка на вопросах без ответа ([X из 6]).
- *А если модель всё равно ошибётся в числе?* В интерфейсе рядом лежит текст источника, а расхождения чисел подсвечиваются.
- *Почему эта модель?* См. `docs/llm.md`: сравнение по отказам, цене, задержке, приватности.
- *Можно ли без внешнего API?* Да, провайдер `ollama` подключён, документы остаются на машине.
