# BankRAG

Помощник аналитика антифрода для выявления сетей дропов. Прототип.
Данные синтетические (IBM AML, NeurIPS 2023). Решение принимает аналитик.

## Методика

### Метка «дроп»

В наборе IBM метки стоят на переводах, а система оценивает счета. Метка счёта считается так:

- **дроп** — счёт и получал, и отправлял помеченные переводы, то есть был посредником в цепочке;
- **прочие помеченные** — остальные счета с помеченными переводами, например начало и конец цепочки. В метриках они не считаются ни дропами, ни чистыми;
- **чистые** — все остальные счета.

Помеченный перевод самому себе не делает счёт посредником.

### Разбиение по времени

Разбиение 60/20/20 считается по числу транзакций, а не по календарю, порядок по времени сохраняется.
В конце периода IBM обычных переводов почти нет: после 10 сентября 2022 осталось 1 108 переводов, из них 59% помечены.
Календарные доли оставили бы в тесте 123 перевода, поэтому метрики считаются на тесте с этим хвостом и без него.

Метка считается отдельно по транзакциям каждого периода. Счёт, который получал помеченные переводы в одном периоде, а отправлял в другом, в каждом из них попадает в «прочие помеченные». Цифры по периодам: `reports/labels_summary.json`.
